# 素材与来源

本项目独立编排研究方法与中文说明。主要方法来源为 Google Search Central 的 [Google Trends Tutorials 十集系列](https://www.youtube.com/playlist?list=PLKoqnv2vTMUO8MUpCbVIiBaDZYrpNF8f-) 与 Google 官方帮助。每条方法在 [methods.jsonl](../skills/google-trends-research/references/methods.jsonl) 关联视频时间戳、官方帮助和核对日期，完整视频索引见 [sources.json](../skills/google-trends-research/references/sources.json)。
